---------------------------------------------
¿QUÉ ES?
---------------------------------------------
HidroLab 360 es una plataforma web educativa
bilingüe (ES/EN) que permite aprender la
hidrostática y el Principio de Pascal mediante
simulaciones interactivas, inteligencia
artificial y gamificación.

---------------------------------------------
CÓMO ABRIR LA PÁGINA
---------------------------------------------
1. Descarga todos los archivos
2. Mantenlos en la misma carpeta
3. Abre el archivo index.html en cualquier
   navegador moderno (Chrome, Firefox, Edge)
4. No requiere instalación ni internet local

---------------------------------------------
ESTRUCTURA DE ARCHIVOS
---------------------------------------------
index.html       → Estructura principal
style.css        → Diseño y colores
main.js          → Tabs e idioma ES/EN
simulador.js     → Lógica Principio de Pascal
animaciones.js   → Canvas: olas y prensa
asistente.js     → Asistente con IA
retos.js         → Módulo de retos y puntuación
assets/logo.png  → Logo del proyecto
assets/qr.png    → QR de acceso en línea
